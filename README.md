# 💬 Modern Chat UI (User Interface)

## Overview
This repository contains a responsive, visually appealing frontend component designed to simulate a modern chat application interface. The project focuses on demonstrating sophisticated frontend techniques, including dynamic layout management and implementing engaging user experience features.

## Key Features
* **Modern Frontend Stack:** Built entirely with **React.js** for a component-based structure and styled professionally using **Tailwind CSS**.
* **Responsive Design:** Ensures a seamless and attractive layout on both mobile and desktop screens (as shown in the mock-up).
* **Dynamic Elements:** The core feature is a **realistic typing animation** implemented within the `ChatRoom.jsx` component, demonstrating skills in component lifecycle management and state-driven animations.
* **Component Reusability:** Designed with modularity in mind, allowing the chat components (message bubbles, user lists) to be easily integrated into a full-stack application.

## 🛠 Technology Stack
* **Framework:** React.js
* **Styling:** Tailwind CSS (Utility-First)
* **Build Tool:** Vite
* **Deployment:** Vercel

## ⚙️ Local Installation and Setup

**Prerequisites:** Node.js (LTS recommended)

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/rotarualexandru22/chatui.git
    cd chatui
    ```
2.  **Install dependencies:**
    ```bash
    npm install 
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    ```
